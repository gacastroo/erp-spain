Importación de datos

Importar Productos y servicios

Añade el catálogo desde una hoja de cálculo usando la misma lógica que el alta manual.

← Volver a productos y servicios

1. Selecciona el archivo

Se admite CSV, XLSX y XLS. Máximo 5 MB y 5.000 filas. La primera fila debe contener los nombres de las columnas.

Los registros válidos se crearán como si los hubieras guardado desde el formulario.

2. Usa una plantilla

Descarga una plantilla vacía para conservar los encabezados correctos.

Descargar plantilla Excel Descargar plantilla CSV

Columnas obligatorias

nombre, precio

Columnas opcionales

descripcion, sku, tipo, iva

En tipo puedes usar Producto o Servicio. Si tipo o IVA están vacíos, se usarán Producto e IVA 21%.

Ejemplo: Mantenimiento mensual;SERV-001;Servicio;49,90;21
